# Khedmti — brand assets

Extracted from `khedmti_charte_graphique.pdf` and applied to the platform.

## Palette
| Token | Hex | Use |
|---|---|---|
| Primary Blue | `#0D7CFB` | actions, buttons, highlights, progress |
| Electric Blue | `#1652A2` | gradient companion, secondary |
| Deep Navy | `#0B111A` | dark background |
| Charcoal | `#1A1D22` | dark cards |
| Pure White | `#FFFFFF` | light cards |
| Soft Gray | `#F4F7FB` | light background |

## Rules applied
- Blue is the action colour — also carries `paid` / `done` / `active`.
- Neutral gray carries `pending` / `draft` / `unpaid`.
- Red is reserved for alerts (overdue, suspended, destructive).
- No orange or flashy green anywhere in the UI.
- The logo always sits on a dark tile, in both themes, per the DO rule.

## Files
- `khedmti-logo-full.png` — presentations, site, video
- `khedmti-wordmark.png` — when the symbol is already present
- `khedmti-symbol.png` — favicon, app icon, avatar (inlined in `index.html` as `LOGO_URI`)
